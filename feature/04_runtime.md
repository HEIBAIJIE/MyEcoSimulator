# F04 运行服务与实验记录

状态：已完成（2026-10-31）。依据：规则0.3 / baseline-1。依赖：F03。

## 目标与来源

提供可控、可查询、可导出的内存运行及五个对照变体。

来源：[运行架构](../spec/world-rules/07_runtime_observation.md)、[历史](../spec/world-rules/06_settlement_history.md)、[变体指标全文](../spec/content-config/03_variants_metrics.md)。

## 实施路径

1. ASP.NET Core提供创建、暂停、单步、速度、快照历史与导出接口；单写入者串行提交，请求标识去重，自动推进与单步共用调度。
2. 保存720回合快照、意图、理由、预留、事件、指标及版本；按主体物品市场回合筛选，串联任务、订单、批次与分录。
3. 聚合价量、生产消费、库存成本、现金分布、工资出勤、饥饿死亡、缺货与停产原因；日汇总按参数版本分段。
4. 实现无居民启动现金、企业资本50分、t=240产量1、t=240消耗4、t=240至263禁新任务五变体。日程初始化公开，旧任务绑定旧配方，新任务引用新版本。
5. 导出配置、版本、快照事件指标；配置可载入开始新运行。声明历史范围、快照间隔及内存预算，容量不足在安全提交边界暂停并允许导出。

## 验收与验证

- 并发重复请求只推进一次，不重入；暂停生效后不调度新回合。超JavaScript安全整数金额及标识用十进制字符串无损传输，基准拒绝手动干预。
- 可从未进食追到预算、订单、成交复核，从未劳动追到任务缺勤或工资失败；申报、有效预留、实际成交分别记录，无成交仍保留有效需求。
- 出勤分母为在世且有合法任务者，0为空；条件进食可得食品0才计缺货。工资、食品支出、死亡充公可核对居民现金变化，国家转移单列；保障分母0未定义，短历史不误判无限购买力。
- 五变体验证不能用未来工资、资本不足不能支付、旧任务保留产量版本、新消耗下D=5、禁发不取消当前任务且解除不保证复产；发行和投资随初始资本同步调整。
- 基准720回合完整历史可查；小预算暂停不删承诺记录、不留半笔交易；导出有回合阶段和版本，不兼容数据明确拒绝，重载配置不承诺同历史。
- 运行接口与五变体验证，记录硬件、规模、耗时和峰值内存，不预设未经测量吞吐目标。

## 范围与扩展

不引入数据库，不要求快照续跑或重启恢复。记录实际随机结果而非可重放随机源；指标服务供F05复用。

实现、验证与性能记录见下文。

## 实现与验证记录（2026-10-31）

- 规则0.3 / baseline-1；依赖F03已通过。入口：`src/EcoSimulator.Api/Program.cs`、核心`Runtime.cs`和`Schedule.cs`；启动及接口示例见根README。未引入持久化。
- 实现创建去重、串行推进、暂停、单步、速度、快照、历史筛选、日汇总及runtime-1导出。Int64统一十进制字符串；配置可重新载入，未知字段及不兼容规则明确拒绝。历史读取事实，不重新运行策略。
- 初始配置公开冲击日程，配方旧版本保留用于已有任务；禁发只阻止当前回合新发布任务。五变体与基准均完成720回合，逐回合核对发行总量及居民现金增量＝工资－食品支出－死亡充公。
- 历史包含申报、有效订单、实际成交、预留、实际动作、任务、决策公式输入、批次变更与复式分录。F02事件事实改为保存实际变化批次，避免每笔事件复制整份库存；回合快照仍完整保存。此为F04变更，不回写F02历史方案。
- 回合指标包含价量、未成交量、实际生产消费、食品数量成本、现金分布、工资支出、国家转移、出勤、饥饿死亡、条件进食缺货及任务失败原因。日汇总按日及参数版本分段；停产详细依据仍通过企业决策输入和公开日程查看。
- `dotnet build -c Release --nologo`：零警告零错误。`dotnet test -c Release --nologo`：32/32通过，约12秒。覆盖并发20次重复单步、暂停后自动调度不推进、请求冲突、拒绝手动干预、小预算安全暂停、超JS安全整数、旧任务产量成本及六种720回合完整历史。
- 实际HTTP验证：创建、重复单步（仍t=1）、主体/物品/市场筛选、导出、提取配置重载成功；服务监听127.0.0.1:5184。
- 硬件：Intel Core i7-12700，20逻辑处理器，物理内存约31.8GiB，Windows/.NET8。单测试进程连续运行六场景（每场景20人、720回合，含查询序列化、完整导出和断言），各约0.8—3.7秒；基准历史计费约162MiB，其他约56—160MiB；测试进程累计峰值工作集约1.56GiB。随机运行不承诺相同终值。
- 内存边界：当前预算是历史UTF-16序列化大小加保守下回合准入预留；不是进程工作集硬限制，导出和.NET对象另占内存。小预算在提交前暂停，不删历史。当前仅支持完整历史与每回合快照，其他快照间隔明确拒绝。无限运行、快照续跑、重启恢复及观察界面不在本feature范围。
