# F02 单回合经济结算

状态：待实施。依据：规则0.3 / baseline-1。依赖：F01。

## 目标与来源

用固定意图完成一次可追溯的生产、工资、交易、消费、生理和清理闭环，不包含自动策略。

来源：[结算全文](../spec/world-rules/06_settlement_history.md)、[市场会计](../spec/world-rules/05_markets_accounting.md)、[动作](../spec/world-rules/04_actions_production.md)、[需求](../spec/world-rules/03_environment_needs.md)、[资产死亡](../spec/world-rules/02_entities_property.md)、[决策边界](../spec/decision-rules/01_agent_decisions.md)。

## 实施路径

1. 实现十阶段管线、不可变快照、意图与结果，区分策略可见视图和观察者全局视图；意图不能直接改世界。
2. 静态预检后冻结交易资格，再统一预留与仲裁：同主体按生存消费、公开劳动、其他动作、出售；共享工资按任务优先级与轮换，无主争抢随机并记录；释放资源不补给失败意图。
3. 处理一个落点和有序免费交互，维护移动→拾取→消费依赖链。动作、订单和免费交互分别失败，权限分开校验。
4. 同质q=1市场求最大成交量K及价格区间L/U，取向下中点；优价优先、边际最大余数分配。买单按限价预留、卖单绑定现货，原子交割并释放差额。
5. 市场后统一复核主动作，条件进食按声明范围使用实际到货；劳动、工资和产品成本同步提交。实现进食、休息、闲置与实际需求状态更新。
6. 清理死亡、组织保管物、现金和投资充公，反馈实际结果。全部状态变化关联事件，非法状态暂停保留输入。

## 验收与验证

- 买10×2、8×2，卖4×1、7×2，均以分计，结果K=3、L=7、U=8、P=7，买方获2和1；小规模穷举验证算法等价。无交叉价为空，双向申报两侧无效但不影响其他人。
- 买到食品可当回合吃，新产出不得当回合出售或供其他动作使用；销售收入和释放资金不能补初始订单预算。失败提交不留下现金、物权、位置或账簿局部变化。
- 睡眠不参与市场，静态失败后按闲置判断资格，市场后失败不重新开放市场；无食品条件进食失败闲置，不临时改睡眠，部分到货按预声明范围吃。
- 饱腹95吃20点食品扣完整1件；饥饿疲惫同时伤10且不叠加恢复，需求转正立即解除状态。成功劳动产2件付100分、产品总成本100分；缺勤失败无工资。
- 死者个人物品无主，组织保管物落地不改权属；P00现金与投资转国家不改企业现金权益。死者无后续意图，无人企业继续存续。
- 用固定意图小场景覆盖争抢、非法移动、重复预留及死亡；逐阶段核对现金总量、账实、唯一位置权属和非负边界，随机并列只验证合法范围与记录。

## 范围与扩展

只启用基准单回合食品配方和同质市场。保留动作进度与阶段接口，不建未来功能的平行结算器。事件先保存在回合结果，查询服务留F04。
