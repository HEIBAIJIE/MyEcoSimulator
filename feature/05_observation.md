# F05 最小观察界面

状态：已完成（2026-10-31）。依据：规则0.3 / baseline-1，含MongoDB运行架构修订。依赖：F04A（沿用F04运行控制与指标）。

## 目标与来源

交付地图、经济曲线和事件追踪共同构成的首个完整产品界面。

来源：[观察要求](../spec/world-rules/07_runtime_observation.md)、[指标](../spec/content-config/03_variants_metrics.md)、[模型解释](../spec/00_index.md)。

## 实施路径

1. React、TypeScript、PixiJS前端接入场景、暂停、单步及速度；已提交快照绘制地块、人员和仓库，同地多人可分别选择。
2. 展示价格量、产量消费、库存、企业现金工资、人口健康曲线，居民现金分布、饥饿出勤、缺货、停产原因和国家充公。
3. 主体详情展示意图理由、预留、结果和保障指标；按主体物品市场回合筛选历史，从结果导航任务、订单、事件与分录。
4. 接入导出，展示版本和固定工资、单企业、不融资分红、禁止个人生产等假设，完成基准及五变体产品冒烟。

## 验收与验证

- 控制通过服务生效，地图详情曲线对应同一已提交回合；20人重叠仍能分别查看，缩放渲染不影响结算。
- 无成交价绘制缺口而非0；参考价、成交价、账面成本区分；有效限价需求、生理需要、实际消费分别显示，大金额无损，零分母显示未定义。
- 用户能追查没买到食品、没劳动、停产、现金不足的实际事件链；分页不丢关联，历史选择不混当前状态。
- 720回合历史可查导出，刷新不重新模拟；策略降价标为假设，不宣称现实因果或长期可持续。
- 使用真实浏览器验证控制、选择、图表、筛选、导航及导出，执行基准与五变体端到端冒烟，记录构建与操作证据。

## 范围与扩展

不增加客户端结算或补贴入口。经济停滞、死亡可通过验收，前提是合法可解释。本条完成才称最小可运行产品交付。

完成时填写：界面入口、构建与浏览器验证结果。

## 实现记录（2026-10-31）

规则0.3（MongoDB架构修订）/ baseline-1。入口 `web/src/main.tsx`、`MapView.tsx`、`data.ts`；API静态文件入口 `/`。React 19、TypeScript 5.9、PixiJS 8、Vite 7，依赖锁定见package-lock.json。

已实现服务端创建六场景、暂停/单步/继续/速度、运行标识恢复、已提交边界选择、地图及同地人员逐一选择、经济与人口健康曲线、现金分布、保障指标输入、意图/预留/结果、完整回合历史筛选与分页、任务/订单/事件/分录/批次查看及浏览器NDJSON下载。历史选中后使用该回合After快照，后续任务另列；不使用当前状态替换历史。无成交价SVG路径断开，零分母为未定义；金额原值字符串保存、格式化与坐标归一化使用BigInt。图形坐标仅作比例近似，详情保留原始值。

服务端补充实际调度状态显示，以及运行中设置速度保持调度。未改变经济规则。F04A已知限制仍按其原记录保留。

验证命令：`npm ci --prefix web`、`npm run build --prefix web`、`dotnet build -c Release --nologo`、`dotnet test -c Release --nologo`、`npm run test:e2e --prefix web`。前端构建通过（主包约522kB，Vite提示包体积建议）；Release构建零警告零错误；后端39/39通过，约4分16秒（与浏览器同时运行）。真实Chromium验证使用本机MongoDB8.2副本集27018，API5184，数据库eco_f05。

首轮浏览器冒烟已完成基准、无居民现金、低资本各720回合、20条分页、历史边界选择、事件导航、722行导出与刷新；因六场景合并测试总时限240秒在第四场超时，未认定为产品失败或验证通过。随后总时限调整20分钟，并改为增量读取历史，重新执行最终六场景。

最终浏览器验收：六场景全部通过，1个组合端到端用例约4.3分钟，真实Chromium无pageerror。每场景720回合，查询第二页20—39、选择结算20对应边界21、订单导航、下载722行NDJSON、刷新仍为720。截图位于web/test-results/{baseline,no-resident-cash,low-capital,productivity,demand,pause}.png。刷新完整历史等待上限30秒，服务端按20回合分页读取；前端当前缓存所选运行最多720回合用于绘图，不代表无限历史扩展已验证。地图20个同地人员分别具有选择按钮和图形标记。后续扩展更长历史应采用指标专用分页和窗口化展示。F04A原有跨实例调度等限制不因F05完成而解除。
