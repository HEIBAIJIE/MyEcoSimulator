# F05 最小观察界面

状态：待实施。依据：规则0.3 / baseline-1。依赖：F04。

## 目标与来源

交付地图、经济曲线和事件追踪共同构成的首个完整产品界面。

来源：[观察要求](../spec/world-rules/07_runtime_observation.md)、[指标](../spec/content-config/03_variants_metrics.md)、[模型解释](../spec/00_index.md)。

## 实施路径

1. React、TypeScript、PixiJS前端接入场景、暂停、单步及速度；已提交快照绘制地块、人员和仓库，同地多人可分别选择。
2. 展示价格量、产量消费、库存、企业现金工资、人口健康曲线，居民现金分布、饥饿出勤、缺货、停产原因和国家充公。
3. 主体详情展示意图理由、预留、结果和保障指标；按主体物品市场回合筛选历史，从结果导航任务、订单、事件与分录。
4. 接入导出，展示版本和固定工资、单企业、不融资分红、禁止个人生产等假设，完成基准及五变体产品冒烟。

## 验收与验证

- 控制通过服务生效，地图详情曲线对应同一已提交回合；20人重叠仍能分别查看，缩放渲染不影响结算。
- 无成交价绘制缺口而非0；参考价、成交价、账面成本区分；有效限价需求、生理需要、实际消费分别显示，大金额无损，零分母显示未定义。
- 用户能追查没买到食品、没劳动、停产、现金不足的实际事件链；分页不丢关联，历史选择不混当前状态。
- 720回合历史可查导出，刷新不重新模拟；策略降价标为假设，不宣称现实因果或长期可持续。
- 使用真实浏览器验证控制、选择、图表、筛选、导航及导出，执行基准与五变体端到端冒烟，记录构建与操作证据。

## 范围与扩展

不增加客户端结算或补贴入口。经济停滞、死亡可通过验收，前提是合法可解释。本条完成才称最小可运行产品交付。

完成时填写：界面入口、构建与浏览器验证结果。
