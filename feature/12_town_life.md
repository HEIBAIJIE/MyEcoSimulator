# F12 小镇生活节奏与昼夜表现

状态：待实施。此会话只完成建议、spec修订与实施计划，未实现、未验收。依赖F11、F07—F09及F04A；规则0.3，新增策略town-life-1与内容town-2。替代F10/F11默认小镇的行为与时间呈现边界，不修改历史记录。baseline-1、town-1及旧存档按原版本运行。

## 问题与交付目标

依据[720回合玩家复盘](../artifacts/f11-review/player-review.md)：699/720回合全员同主动作、76%个人回合闲置、全部人物始终同点，进食固定31回合一次，劳动几乎都在午夜。F11的原地动画不能消除这些行为问题。

交付一个新默认开局：人物依各自显式日程和生存状态选择用餐、休息、工作与闲暇落点，企业在公开工作窗口安排实际需要的生产；地图和事件让玩家读懂这些选择。同步交付昼夜美术与右上角时钟、日历，让“一小时一回合”成为一致、易读且有氛围的体验。

## 建议与范围取舍

1. 补充个人日程、初始需求差异及实际地点选择；差异来自可导出的场景配置，不靠动画随机乱走。
2. 修改默认企业排班，日计划仍在00:00生成，实际任务在工作窗口执行；不强制增加生产，不补贴工资。
3. 优化闲置解释和已有交易反馈。闲暇移动仍是Idle加合法落点，不添加社交、娱乐收益、技能、住房权属或区域物流。
4. 优化时间语义，区分当前提交边界与最近行动。高倍速提供有界事件汇总，避免短事件全部漏看。
5. 优化画面：可辨识的黎明、白昼、傍晚、深夜；右上角模拟时钟盘、数字时间和第N天日历，配合昼夜图标和统一材质。控制条、详情面板、移动端布局同时调整。

不包含住房分配、路径搜索、步行耗时、社交关系、多种食物替代、全新经济部门或改变全球需求消耗。不会为降低同步率修改已结算需求，不以稳定价格、人口存活、持续生产作为完成条件。

## 权威来源与实施入口

- [生活策略](../spec/decision-rules/05_town_life_strategy.md)：完整优先级、地点选择、工作窗口、信息隔离与恢复记忆。
- [town-2](../spec/content-config/04_town_life.md)：默认日程、初值、休息建筑与具体地点；配置展开后导出。
- [运行观察F12](../spec/world-rules/07_runtime_observation.md)：时钟日历、光照、事件语义、空间表现和内存边界。
- 预计入口：Scenario/ScenarioLoader、TownScenario、版本化策略分发及记忆、WorldPresentation/观察事件、持久化恢复、main.tsx/MapView.tsx/style.css及浏览器验收。实施前复核实际类型和序列化模式，不仅在前端外挂日程。

作为一个可交付feature完成配置、决策、恢复、展示和验证，不按内部模块拆成独立“已完成”条目。若实施发现超出会话规模，先调整边界和依赖，不能只交时钟却标记整个F12完成。

## 验收

- 加载：严格校验日程、字段、地点、建筑、工作窗口和策略版本；空首回合任务合法；未支持版本拒绝。新默认town-2、旧存档town-1及baseline-1版本隔离。
- 行为：固定输入验证紧急优先、正常餐时、夜间休息、日间恢复、公开任务、窗口边界、Idle移动与地面库存不可远程消费。饥饿、资金不足、缺勤和失败保持真实后果。随机闲暇选择验证合法候选及实际记录，不断言具体赢家或跨运行序列。
- 信息与守恒：企业不读取私人需求；任务至少提前一回合公开；移动和交易仍经原子预留结算。验证现金、实物和权属守恒，不以模拟长跑代替这些针对性断言。
- 恢复：持续休息、闲暇目的地、任务和必要策略记忆恢复后正确延续；原子保存并查询当时策略和内容版本，不重新抽取已提交选择。
- 720回合：新town-2在真实MongoDB运行一次并导出；统计同动作同步率、Idle比例、实际地点、作息小时、工资/消费/交易及失败原因，与复盘比较。默认前48回合须出现至少两种不同主动作同时存在的回合，至少两名人物发生合法落点变化；不要求同步率永久低于某阈值或每人每天工作。人工检查至少一个人物完整一天及一次任务/交易因果链。
- 时间与美术：检查00、05、08、17、20、23时及跨日、结束720回合、暂停、单步、加速、刷新恢复。时钟日历和光照来自相同提交时间，最近行动单列时间，无假秒针；日夜有明显差异且人物、文字始终可读。
- 浏览器：桌面及390px窄屏，右上角时钟日历不遮详情/关闭/时间控制；键盘与减少动态效果可用。覆盖高倍速跨轮询事件汇总、分页缺口提示、暂停动画及持续画布；检查多组织、多区域、非食品兼容入口没有回退。

预计命令：`npm run build --prefix web`；新增生活策略/配置/恢复相关定向.NET测试及既有TownTests、SpaceEnvironmentTests；F12浏览器测试与game-world、visual-experience相关回归。实现后填写准确命令、通过数量、规则版本、截图路径、720回合运行标识、观察结果及限制。本feature目前所有验证均待执行。
