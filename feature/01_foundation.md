# F01 场景与资产基础

状态：已完成（2026-10-31）。依据：规则0.3 / baseline-1。依赖：无。

## 目标与来源

交付可独立加载、可核对资产的C#核心，为完整回合提供合法输入。

来源：[配置](../spec/content-config/01_configuration.md)、[基准初值](../spec/content-config/02_baseline.md)、[空间](../spec/world-rules/01_space_time.md)、[主体资产](../spec/world-rules/02_entities_property.md)、[市场会计](../spec/world-rules/05_markets_accounting.md)、[架构](../spec/world-rules/07_runtime_observation.md)。

## 实施路径

1. 建立独立核心与测试工程，记录可用.NET版本；API与前端后续接入，核心不依赖网络与渲染。
2. 定义稳定标识、整数分/数量/耐久、规则参数版本，稀疏区域地块及坐标校验。分离成员、员工、职位、股东，以及物品所有权、位置、保管和来源批次。
3. 实现成组分录、资产负债报告、FIFO实际成本、批次拆分来源序号及账实原子提交入口，供F02复用。
4. 分离世界参数、策略参数、内容与运行限制；录入baseline-1初值和首回合任务。校验必填字段、引用、区域重叠、版本及能力开关。

## 验收与验证

- 初始现金400000分、食品180件；P00投资200000分不重复计现金。企业现金投入与期初库存净资产分别说明来源，全部实体账平。
- 20人均在区域(0,0,1)的小地块(0,0)，20项任务有效回合0，含员工、地点、配方版本和工资；小地块范围0至99，区域不能重叠。
- 1分成本3件出库成本依次0、0、1，拆分合并不重置来源序号、不丢成本。
- 缺字段、悬空引用、非法负值、溢出及未支持机制明确拒绝，失败不留下半个运行；关闭工具机制无需伪造参数。
- 使用最小配置和基准初始化测试核对以上断言，核心可脱离HTTP运行。

## 范围与扩展

本会话不推进经济回合。使用固定地块仓库，集合不限制永久人数或企业数；期初事件解释来源，不模拟未定义的历史发行。实际成本账不重估。

## 实现与验收记录

- 规则版本：0.3；配置版本：baseline-1。未修改spec。
- 工具：Windows x64，.NET SDK 9.0.300，目标框架net8.0；独立类库和xUnit测试，无HTTP、渲染或数据库依赖。
- 入口：`Baseline.Create()`生成显式基准场景；`ScenarioLoader.Read/Write`严格JSON加载和导出；`World.Load`构造并对账，成功前不发布世界；`World.Report`读取资产负债；`World.Commit`校验整组分录与候选物品后原子发布。
- `Inventory.TakeFifo`按来源入账顺序和来源区间出库；`Lot.Split/MergeAdjacent`保留原始成本及序号。只有相邻且完整属性一致的来源区间直接合并，不同来源以多个切片保存，不合并摊销基础。
- 初始化43个事件明确发行、居民分配、股东现金投入和期初实物；国家对方科目为期初净资产。P00先获得包含投入资本的分配，再投入F；最终个人现金10000分，投资200000分。企业现金200000分与期初库存10000分分别对应投入权益、期初存货净资产。
- 验证：`dotnet test --nologo`、`dotnet test -c Release --nologo`均5/5通过；`git diff --check`通过。
- 覆盖：基准总现金400000分、食品180件、全实体账平、20项有效回合0任务；最小单人无企业且不同物品标签场景；来源成本0/0/1及拆分合并；坐标边界、重叠、缺字段、未知字段、空必填对象、悬空引用、非法负值、整数溢出和扩展开关拒绝；提交失败后账簿、库存、事件保持不变，合法账实变化可提交。
- 边界：没有回合执行、策略调用、预留或运行服务，留待F02及以后实现。当前策略参数记录初始化需要的窗口、安全库存、试生产与观察期，完整策略执行参数随F03补齐；未将这些字段当作已支持自主运行。工具关闭时耐久为null，不要求工具参数。额外职位和扩展能力明确拒绝；集合和类型不固定20人、单企业或food标签。运行限制显式记录，预算监控由F04落实。
