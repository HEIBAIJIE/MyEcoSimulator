# F03 基准自主运行

状态：待实施。依据：规则0.3 / baseline-1。依赖：F02。

## 目标与来源

接入精确个人和企业策略，无人干预合法运行720回合，保留真实决策依据。

来源：[基准策略全文](../spec/decision-rules/02_baseline_strategy.md)、[主体决策](../spec/decision-rules/01_agent_decisions.md)、[基准](../spec/content-config/02_baseline.md)、[解释边界](../spec/00_index.md)。公式以来源全文为准，本条不替代规范。

## 实施路径

1. 实现策略接口、自身记忆和裁剪快照；企业读员工身份、历史出勤，不能读员工私有需求或本回合未公开意图。
2. 实现个人进食优先、连续休息、任务与闲置；统一D+B-I-A采购，接入库存、预算、报价上限和未完全成交计数。
3. 实现企业日计划、t=0试产、目标剩余量、承诺去重、次回合任务和稳定员工全集轮换；处理t=23暂定次日计划及t=24不能追溯修改公开任务。
4. 实现现货卖量、有界报价、三完整日低价暂停与24回合滞回恢复；反馈只用实际成交和劳动，计划实际分开。
5. 保存理由、公式输入与版本；分别维护成交价、参考价和估值，持续检查不变量并运行720回合。

## 验收与验证

- 饱腹40且精力20先进食，无食品失败仍闲置；休息至至少80，可被饥饿打断。D=120、I=100、R=80、A=B=0时采购20。
- 基准D=3、B=1，常规留100分，紧急可用全额，报价不超170%，数量不超预算；未提交不增不清连续计数，完全成交清零，睡眠不买。
- t=0库存100仍有至少40件试产，后续不每天强制；目标向上到2倍数且最多960，按有效回合mod20轮换，死亡跳过而N不缩小。
- t=23只用当时已知销量，t=24不取消旧任务；当前和未来承诺不重复占目标，不可撤销任务造成的超产独列。
- 无销量日不作亏损单价证据；三完整低价日后次回合暂停，不撤销当前任务；至少24回合后参考价至少60、现金至少100、库存少于20才恢复，任务最早次回合生效。
- 参考价取最近24个有成交回合按量加权向下取整，无成交最新价为空、参考延续，成本账不重估。
- 公式边界测试后运行基准720回合，停滞或全员死亡仍可合法闲置；不要求固定终值或存活。验证策略不能越权或修改快照。

## 范围与扩展

固定工资、无融资分红、无居民转售或个人食品生产不变。策略可替换，基准阈值不进入世界合法性规则。此交付是内部核心，不代表最小观察产品完成。
