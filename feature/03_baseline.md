# F03 基准自主运行

状态：已完成（2026-10-31）。依据：规则0.3 / baseline-1。依赖：F02。

## 目标与来源

接入精确个人和企业策略，无人干预合法运行720回合，保留真实决策依据。

来源：[基准策略全文](../spec/decision-rules/02_baseline_strategy.md)、[主体决策](../spec/decision-rules/01_agent_decisions.md)、[基准](../spec/content-config/02_baseline.md)、[解释边界](../spec/00_index.md)。公式以来源全文为准，本条不替代规范。

## 实施路径

1. 实现策略接口、自身记忆和裁剪快照；企业读员工身份、历史出勤，不能读员工私有需求或本回合未公开意图。
2. 实现个人进食优先、连续休息、任务与闲置；统一D+B-I-A采购，接入库存、预算、报价上限和未完全成交计数。
3. 实现企业日计划、t=0试产、目标剩余量、承诺去重、次回合任务和稳定员工全集轮换；处理t=23暂定次日计划及t=24不能追溯修改公开任务。
4. 实现现货卖量、有界报价、三完整日低价暂停与24回合滞回恢复；反馈只用实际成交和劳动，计划实际分开。
5. 保存理由、公式输入与版本；分别维护成交价、参考价和估值，持续检查不变量并运行720回合。

## 验收与验证

- 饱腹40且精力20先进食，无食品失败仍闲置；休息至至少80，可被饥饿打断。D=120、I=100、R=80、A=B=0时采购20。
- 基准D=3、B=1，常规留100分，紧急可用全额，报价不超170%，数量不超预算；未提交不增不清连续计数，完全成交清零，睡眠不买。
- t=0库存100仍有至少40件试产，后续不每天强制；目标向上到2倍数且最多960，按有效回合mod20轮换，死亡跳过而N不缩小。
- t=23只用当时已知销量，t=24不取消旧任务；当前和未来承诺不重复占目标，不可撤销任务造成的超产独列。
- 无销量日不作亏损单价证据；三完整低价日后次回合暂停，不撤销当前任务；至少24回合后参考价至少60、现金至少100、库存少于20才恢复，任务最早次回合生效。
- 参考价取最近24个有成交回合按量加权向下取整，无成交最新价为空、参考延续，成本账不重估。
- 公式边界测试后运行基准720回合，停滞或全员死亡仍可合法闲置；不要求固定终值或存活。验证策略不能越权或修改快照。

## 范围与扩展

固定工资、无融资分红、无居民转售或个人食品生产不变。策略可替换，基准阈值不进入世界合法性规则。此交付是内部核心，不代表最小观察产品完成。

## 实现与验收记录

- 依据规则0.3 / baseline-1，未修改spec。入口为 `World.AdvanceAutonomously()`；可替换的 `IPersonStrategy`、`ICompanyStrategy` 位于 `src/EcoSimulator.Core/Strategies.cs`。固定意图入口继续保留，运行服务、变体日程和界面由F04/F05实施。
- 个人使用只读自身 `DecisionView`，企业使用 `CompanyView`（自身账簿、库存、市场、稳定员工序列、在世员工身份与公开任务），不传入全局观察快照、员工需求或本回合员工意图。策略仅返回意图与记忆；任务合法性验证后发布，最早次回合执行。任务保留配方版本、工资、产量与地点。
- 实现进食优先、连续休息、条件进食失败闲置、D+B-I-A采购、固定现金保留、紧急预算、报价上限与实际有效订单反馈。自身记忆保留实际工资、支出、未成交量、成交价及动作结果；历史记录完整保存，可查询先前每日支出与出勤。
- 企业日计划使用完整日实际销量，t=0试产最低40件；按食品件数扣实际完成量及已公开承诺。t=23仅用当时已知销量形成次日暂定目标；t=24不撤销旧任务。轮换使用初始员工全集，跳过死亡者但不缩小序列。计划、实际产量与不可撤销任务导致的超产分别记录。
- 三个完整低价日触发次回合停止新任务，零销量日不计亏损单价证据；从暂停生效回合起至少24回合，再按参考价、现金和库存检查恢复。当前任务继续按原有结算器进行资源与出勤预检。现货销售量及80%—110%报价独立于生产成本。
- `AutonomousHistory` 在内存中保存全部自主回合的前后快照、意图、任务、预留、事件事实、实际结果、决策理由、公式输入及规则/策略版本。新任务发布有独立状态事实；参考价延续F02的最近24个有成交回合量加权算法，不重估成本账。
- 验证命令：`dotnet test -c Release --nologo`，23/23通过（原F01/F02共16项，新增F03共7项），Release测试耗时约1秒。公式测试覆盖进食/休息优先、预算、170%上限、未提交/部分/完全成交计数、统一采购20件算例、目标取整及960上限、承诺去重、跨日不可撤销任务、稳定序列死亡跳过、三完整日暂停和24回合恢复边界。
- 完整基准720回合逐回合验证现金总量400000分、各实体资产负债平衡及非负现金、食品期初180件加实际生产减实际消费等于现存数量、任务次回合生效、决策输入和版本完整；t=0库存100件仍实际试产40件，无重复发布。另运行全员死亡后720回合，验证组织仍存续、无死亡者普通意图、无非法暂停。
- 单独构造30个有成交回合并穿插无成交回合，验证最近24个有成交回合量加权向下取整、最新价为空及会计估值100分延续；测试只读视图和无员工私有状态字段。随机竞争不断言固定赢家、终值、存活或价格稳定。
- 边界：此为内部核心；固定工资、单企业基准、无融资分红及个人食品生产等假设保持。库存压力降价属于显式策略假设，结果不能单凭一次运行解释为现实因果关系。完整运行控制、导出、内存预算暂停及指标服务留F04。
