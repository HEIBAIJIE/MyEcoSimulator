# F06 受约束生产

状态：已完成（下述明确范围）。依据：规则0.3，新增场景策略独立版本。依赖：F05（已完成）。

## 目标与来源

交付原料工具耐久约束下的生产、独立步骤多回合动作及明确的采购策略实例。

来源：[生产步骤全文](../spec/world-rules/04_actions_production.md)、[企业生产采购](../spec/decision-rules/01_agent_decisions.md)、[成本](../spec/world-rules/05_markets_accounting.md)、[配置](../spec/content-config/01_configuration.md)。

## 实施路径

1. 启用执行资格、原料工具提供方、授权、共享性、耐久和完整整数步骤。工具价值消耗政策若未明确，先小范围补spec再实现，不能隐藏选择。
2. 复用预留与原子事件扣完整投入和耐久，归集材料工具劳动成本并产出，实际劳动才支付工资，零耐久回合末清理。
3. 实现动作开始继续完成中断预检失败，逐回合重检且仅留本回合资源；中断保留合法完成步骤并释放未用预留。
4. 累计向下取整差值用于数量分摊，但加载时须证明每个产出步骤有完整投入；无法拆分且无在制品规则的配方拒绝。
5. 配置显式版本采购策略与小场景：工资优先、D+B-I-A、明确预测窗口、试产、报价和停复产公式；市场后复核完整步骤，反馈计划实际差异，观察失败与成本链。

## 验收与验证

- 缺原料或授权整步无产出无工资；独占工具不重复用，耐久归零不会多执行；提供方不同仍需权限。
- Q=5,H=3分摊1、2、2；投入1产出2时长2但首步无投入产1的配方拒绝，反复中断重启不套利。
- 部分采购不够整步则生产失败但保留购买，不临时缩配方；D=120,I=100,R=80时采购20，未成交不算到货，不使用未来工资。
- 用断供、工具竞争、耐久耗尽和中断场景核对数量成本现金，回归基准720回合不变量，新策略不改变baseline-1。

## 实现记录（2026-10-31）

规则0.3 / production-1 / procurement-1。新增工具实际成本累计折耗和跨提供方投入权益规则，见市场会计；采购公式见 `spec/decision-rules/03_production_strategy.md`。基准 baseline-1 保持原策略及机制开关。本条对规划边界作明确收紧：只启用独立一小时步骤、独占工具、单企业单工种与同质原料市场；共享工具明确拒绝，待容量和耐久竞争规范完善后另立 feature。耐久工具市场因动态质量尚未实现而拒绝交易。不可拆分在制品继续拒绝。每一步含全部材料类型，不能把欠付投入延迟到后步。
