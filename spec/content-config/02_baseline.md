# 基准初始条件 baseline-1

[返回总览](../00_index.md)

## 基准配置

| 项目 | 固定值 |
| --- | --- |
| 时间 | t从0开始，720回合；每天t mod 24=0制定计划 |
| 世界 | 区域(0,0,1)，100×100小地块，全部平地，无建筑和地表实体 |
| 主体 | 国家S、企业F、人员P00至P19；标识固定 |
| 组织关系 | 全体属于S和F；均为F食品员工，无额外职位；P00持有F全部股权 |
| 位置 | 全体初始位于(0,0)，企业固定仓库亦为(0,0) |
| 现金 | 每人10000分；企业200000分；国家0；期初现金总量400000分 |
| 股权 | P00投资资产200000分，对应F期初投入权益；死亡后股权及投资账面额收归S，不自动重估 |
| 食品 | 唯一标签food，质量1，可装物品栏，无耐久、腐坏或工具用途，每件饱腹值20 |
| 期初库存 | 每人4件、每件成本100分；企业100件、每件成本100分；来源为明确期初实物配置 |
| 需求初值及上限 | 健康100、饱腹100、精力100，上限均100 |
| 消耗恢复 | 未进食饱腹每回合减2；未休息精力减4；休息每回合加20；饥饿、疲惫分别伤健康5；两项需求均至少60且无伤害时健康加1 |
| 配方 | 员工每劳动回合产食品2件，无原料工具要求，企业独占配方；工资100分/回合 |
| 价格 | 初始参考价及初始食品估值100分；成本账不重估；参考窗口最近24个有成交回合，成交量加权平均后向下取整，尚无成交沿用100分 |
| 订单 | 每人最多一张food买单，F最多一张food卖单；每回合有效，无转售 |
| 模块开关 | 不启用融资、分红、辞退、个人生产、多质量、多区域、搬运、建筑、通用多回合配方及手动干预 |

期初每人食品资产400分对应期初净资产；P00另有企业投资资产。企业库存10000分对应期初存货净资产，不计作P00现金投入。所有期初资产均由独立初始化事件说明来源，不把期初实物当作运行中生产。国家期初货币发行采用期初净资产对方科目，随后分配与资本转移事件必须可对账；最终现金分配和投资来源须与上表一致，不重复发行。

死亡在清理阶段执行。死者不再参加计划；投资收归国家，不再安排其任务；组织存续。初始首回合任务为20人各一回合劳动，任务有效回合为0，实际生存动作仍优先。

## 运行范围

基准运行720回合，允许经济停滞后继续合法闲置；人口为0时保留组织状态和历史。基准使用[基准策略](../decision-rules/02_baseline_strategy.md)。
