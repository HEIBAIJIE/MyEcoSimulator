## 场景变体与观察指标

每个变体明确规则、参数版本及与基准的字段差异，用于观察初始条件和外生变化对经济过程的影响。

| 变体 | 唯一或明确变更 | 观察对象 |
| --- | --- | --- |
| 基准 | 无 | 全流程运行与事件解释 |
| 居民无启动现金 | 每人现金0，发行总量相应减少 | 不超额买入，工资到账前不能使用未来收入 |
| 工资资本不足 | 企业现金50分，股东投资与发行同步调整 | 不支付负现金工资，已有任务失败可解释 |
| 生产率冲击 | t=240起每工时产量1，作为预先公开场景日程 | 变更按有效回合执行，产出成本一致 |
| 需求冲击 | t=240起自然饱腹消耗4 | 生理需要、有效订单与实际消费分离 |
| 暂停与恢复 | t=240至263禁止发布新任务，264解除此开关 | 组织资产保持，恢复仍须满足原策略和现金条件 |

冲击日程须在初始配置中公开；规则内每日与每回合预测在生效回合使用新值，例如需求冲击后D=ceil(24×4/20)=5。配方变更不追溯旧有效任务；旧任务沿用任务中配方版本，新任务引用新版本。禁发任务不会取消已公开当前任务，暂停不承诺实际产量立刻归零。

指标按回合记录，日汇总不跨版本混算：成交价、量、有效限价供需、未成交量；实际生产消费、食品数量与账面成本；居民现金总量及分布、企业现金、国家现金；实际工资、出勤率、饥饿人数、死亡、缺货回合与停产原因。出勤率分母为当回合在世且有合法公开任务者，分母0记空；缺货回合指已声明条件进食但可得食品为0，不把未提交订单自动算作市场拒绝。

同一变体允许多次运行以观察随机竞争对个体结果的影响，不把单次运行视为普遍规律。个人生产对照因改变现有资格制度，留给后续规则版本，不在当前基准偷偷开放。
