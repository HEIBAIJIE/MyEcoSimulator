# 主体决策与信息边界

[返回总览](../00_index.md)

## 决策

### 一、决策的共同基础

所有主体只能依据回合初快照和自身历史记忆进行决策，不能读取其他主体本回合尚未公开的意图。

决策只生成移动、动作、免费物品交互和市场订单等意图，不直接修改世界状态。意图是否生效，由统一的合法性预检和结算阶段决定。

主体至少需要保存以下历史记忆：

各物品近期成交价、参考价格、成交量和自身订单的未成交量；

自身近期每日必要支出；

自身近期收入或工资；

企业近期产品销量、原料消耗量和生产量；

当前库存、已预留库存以及生产中或确定即将获得的数量；

最近决策未执行、未成交或未完成的原因。

参考价格不能简单等于上一回合的最新成交价。主体应当根据近期实际成交价形成参考价格；近期没有成交时沿用上一次有效参考价格；从未发生成交时使用初始参考价格，并可以参考生产成本进行调整。

决策分为两个频率：

**每日计划**：确定必要支出预算、目标库存和企业生产计划等较稳定的计划；

**每回合调整**：根据当前需求、动作进度、库存、现金和上回合执行结果，决定进食、休息、劳动、临时补货和订单调整等具体意图。

每日计划不应因单回合的轻微波动而频繁重做。

### 二、人的财务健康状况

人的决策应当同时考虑现金、必要支出和必要物资，而不能只考虑现金余额。

人的财务状况至少包括以下指标：

**可用现金**：现金余额减去已预留资金。

**必要支出预算**：未来一段时间内为食物等基本需求预留的支出。当前阶段可以主要考虑未来一至两天。

**现金保障天数**：可用现金除以近期每日必要支出。近期每日必要支出可以根据自身历史支出估计。

**必要库存保障时间**：现有食物等必要物资，按照预计消耗速度还能维持的时间。

现金较多但缺乏必要物资时，仍应优先获取必要物资。

现金不足但必要物资充足时，不一定需要立即出售生产工具或其他重要资产。

可用现金不足以同时满足全部需求时，应当优先保障基本生存需求，再考虑一般消费和改善性支出。

### 三、人的动作决策

人的动作决策应当取决于其财务健康状况、自身需求满足情况、所处组织及当前动作进度。

当前阶段按照以下优先级生成动作意图：

（1）处理生存紧急情况。

饱腹度或健康状况危急时，优先进食；精力严重不足时，优先休息。进食所需食物可以来自物品栏、所在小地块，或者本回合市场结算后新买入的物品。

（2）维持必要的多回合动作。

已经完成较大部分的劳动、搬运等多回合动作，不应仅因轻微波动而频繁中断。出现生存紧急情况、动作条件失效或组织计划发生重大变化时，可以中断。

（3）履行组织安排的工作。

有工作且满足工作条件时，默认参加组织劳动。企业负责制定生产计划并发布工作任务，员工在满足基本生存需求的前提下执行。

企业安排工作不等于无条件控制员工的全部动作。员工出现严重饥饿、疲惫或其他生存紧急情况时，基本生存需求优先于企业任务。

（4）自行获取短缺资源。

无工作、工作无法继续，或者现有工作与库存无法保障基本生活时，可以自行生产、采集、搬运或购买短缺资源。

（5）改善性活动或闲置。

基本需求和工作安排均得到处理后，可以执行其他改善性动作；没有合适动作时闲置。

进食和休息不应只使用单一固定阈值。即将开始长时间劳动时，可以提前进食或休息；普通需求尚不紧急时，可以短暂维持当前劳动；进入饥饿、疲惫等危险状态后，生存需求优先。

### 四、人的市场决策

人的市场决策按照“预测需求—计算缺口或盈余—检查预算—生成订单”的顺序进行。

当前阶段，人主要为自身消费和劳动采购物品，不主动以低买高卖为目的进行投机交易。

#### 买入决策

人应当预测未来一段时间内需要消耗的食物等物资。

目标持有量＝预计消耗量＋安全库存。

买入量＝目标持有量－现有可用量－确定即将获得的数量。

现有可用量应当扣除已经预留用于其他用途的物品。

买入量还应受到现金预算限制。购买后应当尽量保留必要支出预算，不应仅因库存目标较高而花完全部现金。

最高买价以参考价格为基础，并根据以下因素调整：

需求紧急程度；

现有必要库存保障时间；

现金保障天数；

近期订单未成交情况；

物品质量乘数。

需求越紧急，可以提高最高愿意支付的价格；现金紧张时，应降低购买数量或报价，而不是无限制提高报价。

#### 卖出决策

人只出售超过自身安全库存、且未被其他计划预留的物品。

不主动出售维持基本生活或当前工作所必需的工具。

最低卖价以参考价格为基础，并结合物品质量、库存压力和现金压力调整。

订单连续未成交时，可以在后续回合调整价格或数量，但不能在同一回合内重复提交并反复出清。

部分成交时，应当根据实际成交量重新计算库存和后续需求。

### 五、企业的生产与用工决策

企业应当先决定生产量，再由生产计划推导原料采购、产品销售和员工工作任务。

企业生产量依次受以下条件约束：

近期预计销量和目标产品库存；

员工数量和预计可用劳动时间；

可用原料及其安全库存；

可用现金、必要支出预算和工资储备；

工具、建筑和其他生产条件。

企业可以根据近期实际销量估计未来销量。近期没有销售记录时，应当采用保守的初始生产计划，而不是默认市场需求无限。

目标生产量应当考虑现有产品库存、已预留产品和生产中的产品，避免重复安排生产。

由计划生产量生成：

本回合及后续回合的原料需求；

产品库存计划；

员工工作任务；

本回合工资支出；

是否继续、缩减或暂停生产。

企业不应在现金不足时仍机械地买满原料，应当优先保留本回合劳动所需的工资和必要支出。

企业现金不足以支付本回合工资时，不安排相应劳动。

如果长期预期生产亏损，或者产品持续滞销，企业应当减少或停止生产，而不是继续采购并扩大库存。

当前阶段不考虑企业退出，因此企业可以处于“保留组织但暂停生产”的状态。暂停生产期间不安排新的企业劳动，也不产生相应的小时工资。

### 六、企业的市场决策

企业的市场决策应当取决于主营业务、生产计划、原料和产品库存、现金状况、工资储备及近期成交情况。

#### 原料采购

原料采购量由计划产量、单位产品原料消耗、现有可用原料和原料安全库存共同决定。

原料采购按本篇统一需求口径计算，不再次扣减已预留原料，并受现金预算约束。

最高买价以参考价格为基础，并根据原料库存保障时间、生产紧迫程度和现金状况调整。

不得为了维持不必要的满负荷生产而耗尽工资储备。

#### 产品销售

产品销售量原则上为超过产品安全库存、且未被其他生产计划预留的产品数量。

企业也可以根据现金压力和库存压力出售安全库存中的一部分，但应记录相应决策理由。

最低卖价以参考价格为基础，并结合产品质量、库存压力、现金压力和近期未成交情况调整，而不是简单地在成本上增加固定比例。

企业可以因现金压力或库存压力降低报价，但长期售价无法覆盖持续生产成本时，应当触发减产或停产评估。

#### 未成交与持续失衡

原料订单连续未成交时，可以调整报价、减少采购量或缩减生产计划。

产品连续滞销时，可以调整报价，并减少后续生产。

产品持续缺货时，只能在员工产能、原料和现金允许的情况下增加生产，不能仅通过提高采购报价虚增产量。

### 七、决策反馈与可解释性

每回合结算后，主体应当根据实际结果更新历史记忆，包括：

订单全部成交、部分成交或未成交；

实际成交价格和成交数量；

动作完成、被打断或预检失败；

实际收入、支出和工资；

库存及预留库存变化；

需求未满足的程度；

生产计划的实际完成情况。

后续决策应当使用实际执行结果，而不是假设所有意图均已成功。

每个主体的每回合意图应当记录一条或多条简明的决策理由，例如：

“饱腹度低，购买食物”；

“现金不足，缩小采购量”；

“原料不足，暂停劳动”；

“产品库存过高，降低生产量”；

“连续未成交，调整报价”；

“现金不足以支付工资，不安排本回合劳动”。

决策理由应当与实际生成的意图一同保存，以便观察和回溯主体行为。

## 决策参数表

以下概念必须转化为可配置参数或明确公式，不能只保留自然语言描述：

| 概念 | 至少需要明确的配置 |
| --- | --- |
| 近期成交价、销量和支出 | 窗口长度、是否只使用有成交回合、缺失值处理 |
| 危急、严重不足和危险状态 | 健康度、饱腹度、精力值的具体阈值 |
| 必要支出预算 | 预测时长、每日支出估计方式、最低现金保留量 |
| 安全库存 | 预测消耗量、安全系数和库存上限 |
| 轻微波动 | 不重做每日计划、不中断动作的容差 |
| 报价调整 | 调整步长、最高与最低倍数、连续未成交次数、冷却时间 |
| 库存压力和现金压力 | 指标公式、触发阈值和报价调整上限 |
| 保守初始生产计划 | 初始试生产批量、员工与原料约束、最低观察期 |
| 减产、停产与恢复 | 进入和退出阈值、持续回合数及滞回条件 |

参数应随场景配置保存，并记录版本。历史查询应能查到当时实际使用的参数。

## 动作决策状态机

人的动作优先级保留本篇顺序，并通过显式状态机处理生存紧急、继续多回合动作、履行工作、自行获取资源和闲置之间的转换。每次转换至少记录触发原因、被打断动作、已完成进度和未使用资源释放结果。

相同优先级的可选动作可按效用分数选择；分数相同时允许随机选择，记录实际选择及理由。

## 公开工作安排与生效时点

企业工作任务属于回合初快照中的公开信息，至少包含任务标识、企业、员工、劳动类型、地点、有效回合、工资条件和计划产出。初始场景必须给出首个回合已经生效的工作安排。

企业在回合 \(t\) 新生成、修改或取消的计划任务，默认从 \(t+1\) 或更晚回合生效；员工不得依据企业本回合尚未公开的意图行动。因本回合现金、原料、工具或权限预检失败而取消实际劳动，不属于秘密修改任务，但必须向相关员工反馈失败原因。

员工只执行回合初已公开且本回合生效的任务，并仍可按生存紧急程度缺勤。企业根据历史出勤和当前公开信息估计可用劳动，实际产量、工资和投入只按实际参加并通过执行前复核的劳动结算。

## 依赖市场结果的条件动作

主体预计使用本回合买入物品进食或生产时，应同时提交市场订单和条件动作意图，并声明市场结算后的用途。条件动作不把未成交订单视为既有资源，也不在动作前预检中因暂时缺少拟购物品而直接失效；市场结算后必须按实际获得的物品再次复核，失败时转为闲置并记录原因。

首个最小场景中，“自行生产短缺资源”不包括自行使用企业食品配方。食品只能由企业员工依据公开工作任务生产，产出归企业所有。

## 市场报价的有界调整

主体可以根据紧急程度和连续未成交情况调整报价，但调整应受预算、库存和配置倍数限制。需求紧急不意味着可以提交超过可用现金的订单，现金压力也不意味着卖价可以低于最小报价单位。

每日计划保留稳定性，每回合调整只修改允许调整的数量、报价或动作。减产、停产和恢复生产宜采用不同阈值或持续观察期，避免在相邻回合反复启停。

## 经济启动与初始试生产

“近期没有销售记录时采用保守生产计划”不能默认等同于生产量为0。首个最小场景必须配置可解释的启动条件，包括：

- 初始个人与企业现金；
- 初始食品和其他必要库存；
- 初始参考价格与会计估值；
- 企业初始试生产批量；
- 试生产期间可接受的观察回合数。

企业仍受员工、现金和工资约束，不能为了启动而无视偿付能力。若初始条件无法支持任何生产和消费，应将结果解释为场景启动失败或经济停滞，而不是让主体凭空获得资源。

## 计划量与实际量分离

需求预测、目标库存、计划采购、计划生产和实际获得数量分别记录。确定即将获得的数量必须有在制动作、已成交事件或其他可验证依据，不能把尚未成交的买单直接视为未来库存。

部分成交、动作中断和员工缺勤后，应在反馈阶段重新计算缺口。下一回合不得继续沿用本回合已经失效的计划数量。

## 决策理由的机器可读记录

除自然语言理由外，建议同时保存稳定的原因代码，例如“生存紧急”“现金不足”“原料不足”“库存过高”“连续未成交”和“工资储备不足”。一条意图可以对应多个原因代码，并记录关键参数、使用的价格、计划量和实际量，以便筛选、统计和历史查询。

## 统一需求口径与信息边界

预测区间总需求D包含尚未执行的已承诺需求R；现有库存I包含预留；可验证到货A不包含未成交订单；期末安全库存B。新增采购=max(0,D+B-I-A)，再受预算限制。等价地以D-R减I-R，不能只一侧扣R。D=120、I=100、R=80、A=B=0时采购20。人和企业统一采用此口径。

公开信息为市场历史有效订单汇总、成交价量、参考价格、公开规则、已发布任务。其他主体现金、需求、个人库存、私有预测和未公开订单不可读。个人读取自身状态、权限和相关任务；企业读取自身账簿、员工身份、公开资格和历史出勤，不直接读取员工私有饱腹精力。全局观察者权限不传递给决策器。

阶段间实际状态仅供结算器复核预先声明条件，不再次调用策略改价或切换动作。条件进食可预先声明最多n件、最少1件，按实际到位量食用；固定产量生产必须满足完整投入，不能临时缩减配方。

### 休息与睡眠

当前阶段将睡眠视为休息的主要动作。精力按实际完成结算的休息回合恢复；动作被预检拒绝或提前打断时，只保留已经完成回合的效果。主体可以因生存紧急情况或更高优先级规则主动醒来，具体阈值和最短连续休息时间由决策参数配置。
