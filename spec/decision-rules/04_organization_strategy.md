# organizations-1 多企业策略与授权实例

规则0.3的独立场景策略，不替换 baseline-1 或 procurement-1。当前启用范围为单区域、同质食品、独立一小时配方；production-1 与 organizations-1 组合尚未实现，加载时拒绝。大件搬运由F08追踪，carry权限目前只约束携带组织物品的区域内移动。

每个企业显式保存策略版本 organizations-1、SafetyStock、SellPercent（80至110）和 Paused。每个工种由唯一配方定义正整数固定工资与产量，并配置非负任务优先级，小值优先。成员、员工、股东和职位分别校验，职位不授予管理能力或隐含权限。

共享规则必须显式为 priority-rotation-1。个人沿用基准生存优先阈值；多个公开任务先按工种优先级，再按场景配方稳定全集从 t mod N 轮换选择，只声明一个主动作。死亡者不参加选择，稳定全集不删项重编号。企业工资不足时，按任务优先级及初始员工稳定全集轮换预留工资，无替补。

各企业只依据回合初自身现金、库存、员工和公开市场信息发布次回合任务。每日目标=max(0,上一日实际销量+SafetyStock-现货)，初始预计销量为Strategy.TrialProduction，首日至少试产该数量；日内目标固定。剩余目标扣已实际产量与当前公开任务产量，截断为0。按有效回合轮换员工，跳过死亡者和无劳动授权者，按配方顺序为工种预算固定工资，预算或目标不足则不发布。跨日任务沿用当时已知目标，不追溯撤销。Paused或公开暂停日程阻止新任务，不撤销当前已公开任务。该策略不承诺盈利或存活。企业卖量=max(0,现货-SafetyStock)，报价=max(1,floor(参考价×SellPercent/100))。个人采购及反馈沿用基准公式。全部企业在同一食品市场统一出清。

view只提供查看；pickup与custody同时具备才可把组织货物装入个人物品栏；carry才可携带其移动；drop才可放下；consume才可消费；sell才可代企业出售。MarketOrder.Actor为空表示经济实体自身决策，非空时必须是存活人员，代表其他实体只允许获得该实体sell授权的卖单，现金与收入仍归被代表实体。持股、员工、成员和职位不推导上述权限。权限按组织标识匹配，不跨组织继承。

无成员、无员工、暂停不解散组织。缺勤或选择其他任务、工资不足、静态权限失败和策略暂停分别保留结果或决策记录。当前不启用共享工具、管理、择业、辞退、融资分红或组织成立解散。
