# 我的经济模拟器

## 目标与阅读方式

通过模拟直观理解现代经济社会的运行过程，首先观察工资、消费、生产、库存、现金约束与食品价格的相互作用。模拟结果须结合规则、初始条件与策略假设解释，不能直接作为现实经济规律的证明。

文档按“世界是什么、主体如何选择、具体放入什么”分层。世界规则规定合法状态与状态变化；决策规则生成意图，可以调整策略；内容配置提供物品、参数、主体及初始条件。技术架构与观察能力作为世界运行的支撑约定列在世界规则目录末尾。

## 统一规范

当前规则版本为 `0.3`，基准配置版本为 `baseline-1`，基准具体决策采用本版本基准策略。相较旧版，本版取消确定性历史复现并按主题归并规则；不存在“原始规则”和“补充约定”的优先级。一般定义、当前能力边界、基准专属约束分别在正文中明确；基准参数和策略是实例，不限制其他场景使用通用能力。

“必须”“不得”及明确公式为规范性约束；建议性表述允许选择。场景可在允许范围内选择参数或收紧能力，不得覆盖守恒、权限和原子性。缺少启用机制必需字段、引用未定义状态或机制时拒绝加载，不使用隐含默认值。

- 意图不直接修改世界，经过预检、资源预留与统一结算。
- 主体依据回合初可见快照及自身历史决策，观察者权限不传给决策器。
- 现金、实物、权属、位置和账簿变化原子提交且可追踪。
- 无成交时最新成交价为空，参考价和会计估值按规则延续。
- 允许随机选择与随机竞争结果；同一场景及参数的多次运行可以产生不同历史。不要求固定随机种子、固定随机算法、哈希裁决、确定性重算或跨运行历史一致。
- 身份标识用于关联对象与事实；整数分、整数物品和投入分摊用于金额精度与实物合法性，不承担跨运行复现职责。
- 记录实际决策理由、执行结果与事件，保留对已发生过程的解释能力。

测试场景、自动校验清单和技术验收方案暂不纳入本 spec；后续从 feature 拆分维度制定。世界合法性约束仍然有效，发现非法状态不得用自动补贴、虚构资源或补记权益掩盖。

## 观察与解释边界

不要求经济持续运行、现金均衡、价格稳定或人口长期存活。不得为这些结果自动补贴、融资、修改固定工资或开放个人食品生产。停产、停滞和死亡允许发生，须能追溯到规则、事件及策略。

### 模型假设与现金流解释

工资是外生参数，当前不解释工资形成、劳动市场竞争或自由择业。单企业、不分红、不融资、禁止个人使用食品配方均为强场景假设，报告须随结果显示。食品只需劳动而不能个人生产，来自生产资格制度，不是技术上的自然限制。

没有其他转移时，居民现金增量＝工资－食品支出，企业现金增量相反；死亡充公另列国家转移。初始资本支持的暂时运行不等于长期循环，此关系仅用于核对现金来源，不增加经济可持续性要求。

库存高则降价等直接编码行为须标记为策略假设；振荡、现金集中或恢复失败等交互结果才是进一步观察对象。事件链是规则内过程追踪，不单凭一次运行声称现实因果关系。
